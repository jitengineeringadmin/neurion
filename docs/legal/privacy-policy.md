# Privacy Policy

## Data processed
Account data (email, hashed password), usage (chat/jobs metadata), wallet address (if linked), node telemetry.

## Prompt confidentiality (G2)
Chat defaults to VERIFIED_ONLY routing: a community (stranger) node never sees chat plaintext by default. A pre-dispatch classifier can only RAISE the privacy level. Special-category/credential content is hard-blocked from community nodes. An optional anonymous open tier exists with explicit consent.

## Lawful bases (GDPR)
Art.6(1)(b) service performance for the default trusted path (Art.28 DPAs with verified operators); Art.6(1)(a) consent for the anonymous open tier; Art.9 data kept off untrusted hardware.

## Retention
Job inputs deleted after retention; outputs configurable; users can delete stored outputs; audit/accounting retained separately.

## Rights
Access, rectification, erasure, portability, objection — contact the DPO.
