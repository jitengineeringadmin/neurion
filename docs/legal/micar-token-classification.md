# NRN — MiCAR Token Classification

## Classification
NRN is intended as a **utility token** under Regulation (EU) 2023/1114 (MiCAR): it provides access to AI compute services on the Neurion network. It is NOT an e-money token (EMT) or asset-referenced token (ART): no peg, no redemption right, no claim on an issuer.

## Rationale
- Sole function: pay for / reward verified useful compute (see tokenomics).
- No profit expectation marketed (UI wording rules forbid APY/return/price language — enforced in product).
- Non-custodial: the platform never holds user private keys.
