# Data Processing Addendum (DPA)

Applies to verified/enterprise node operators acting as processors.
- Process personal data only on documented instructions.
- Confidentiality + no-retention (ephemeral context) obligations.
- Technical/organisational measures per Art.32; TEE attestation where applicable.
- Sub-processing only with authorisation; assist with data-subject requests and breach notification.
- Community (unvetted) nodes have NO DPA and therefore never receive identifiable/sensitive data.
